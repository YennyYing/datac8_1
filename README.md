# World Population and Poverty 

## Description
This project analyzes global population trends using data from Gapminder’s Systema Globalis. Using Python, NumPy, and the Datascience library, we explore how population, life expectancy, child mortality, and fertility have changed over time, focusing first on Poland and then expanding to global patterns.

## How It's Made:

**Tech used:** Tech used: Python, NumPy, Datascience library, Matplotlib, Jupyter Notebook

This project was developed in Python using the Data 8 datascience library to clean, filter, and analyze population and demographic datasets from Systema Globalis. I used **NumPy** for array operations, **Table** objects for data manipulation, and **Matplotlib** for plotting.

The analysis begins with isolating Poland’s population data using ISO Alpha-3 country codes, generating summary tables, and computing growth rates across 5-year intervals. Then, additional datasets—life expectancy, child mortality, and fertility—are integrated to study how demographic indicators relate to long-term population trends.

Throughout the notebook, I used table joins, column transformations, grouped summaries, relational filters, and custom arrays to compare patterns across multiple datasets. Line plots and scatter plots were created to explore temporal trends and relationships between variables such as fertility and under-5 mortality.
This project demonstrates how standard Python tools can be combined to perform exploratory demographic analysis and uncover relationships between population growth, health outcomes, and fertility patterns.
